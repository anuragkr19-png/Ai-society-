## Running it

```bash
pip install numpy pandas scipy scikit-learn matplotlib
jupyter notebook CSET485_Assignment1_S24CSEU1224.ipynb
```

Run all cells top to bottom. The notebook downloads `german.data` from UCI and falls
back to the local copy in this repo if the machine is offline. Every number and figure
cited in the report is regenerated by this run — nothing is hard-coded.

No `statsmodels` dependency: logistic regression is fitted by unpenalised
Newton–Raphson MLE implemented in the notebook, with standard errors from the inverse
observed Fisher information. `sklearn.LogisticRegression` is deliberately not used for
inference because it applies L2 regularisation by default.

## Headline results

- **Part 1** — the median-cutoff and 0.50-cutoff rules disagree on **83 of 300 cases (27.67%)**, in one direction only. Spearman rank correlation between the two scores is 0.9903: the models agree on ranking and differ only on where they cut.
- **Part 2.1** — the coefficient on age is **+0.4810 (p=0.0027)** for women and **−0.0322 (p=0.7565)** for men; pooled it is +0.1628 (p=0.0515). Interaction age×female = +0.4922, p=0.0069, LR χ²(1)=7.70.
- **Part 2.2** — dropping `credit_amount` moves duration's coefficient by **−48.14%** (1.33 SE) while test AUC falls only **0.0061**. The OVB formula predicts the sign of the shift correctly for 6 of 6 predictors.
- **Part 2.3** — **26 high-confidence errors (8.67%)**. Zero of 20 recorded attributes separate the 24 confident false approvals from the 143 correct ones; cross-validated AUC inside the band is 0.5501 against chance 0.50. Adding interaction terms does not reduce the error count.
- **Part 2.4** — no threshold satisfies DP, EO and PP simultaneously. The only point reaching DP = EO = 1.0 is t=0.05, which approves every applicant.
